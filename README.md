# العصر الحجري

## الرفع على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع **كل** الملفات في الجذر (بدون مجلد داخلي).
2. Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `(root)`.
3. افتح الرابط من المتصفح في الجوال ثم: «إضافة إلى الشاشة الرئيسية» (Chrome) أو Share ← Add to Home Screen (Safari).

ملاحظة: يحتاج التطبيق إنترنت أول مرة لتحميل Tailwind والخط، ثم يعمل التخزين المؤقت للملفات.
